# setora-media

Setora uygulamasının hareket görselleri (çizim tarzı, 600 px WebP).

- `erkek/<hareket>_erkek_<start|end>.webp` — 519 hareket, 941 poz
- `manifest.json` — sürüm + dosya özetleri (uygulama değişen görselleri buradan anlar)

Uygulama bu dosyaları jsDelivr üzerinden okur:
`https://cdn.jsdelivr.net/gh/codeabchome/setora-media@main/erkek/<dosya>`
